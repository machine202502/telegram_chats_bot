# telegram_chats_bot — Windows-обёртка

Это **не часть контейнера**, а небольшое нативное окно для Windows. Оно
открывает уже работающий веб-интерфейс из Docker как обычное приложение,
умеет сворачиваться в трей и показывает иконку приложения в трее и на панели
задач.

## Запуск

Если зависимости ещё не стоят — один раз запустите **`install.bat`** (создаст
`.venv` и поставит `pywebview`, `pystray`, `Pillow`).

Дальше — двойной клик по **`start.bat`**.

Скрипт:

1. проверяет, запущен ли Docker-стек, и при необходимости поднимает его;
2. открывает окно WebView2 с `http://127.0.0.1:8000`;
3. сворачивает окно в трей по крестику.

Если нужен лог при запуске — используйте `start-console.bat`.

## Остановка

- Крестик окна — **скрыть в трей**, приложение продолжает работать.
- Правый клик по иконке в трее → **Выход** — закрыть окно; контейнер
  продолжит работать.
- `stop.bat` — остановить контейнеры приложения.

## Трей

- Левый клик по иконке (или пункт «Открыть») — показать окно.
- «Свернуть в трей» — скрыть.
- «Выход» — закрыть окно-обёртку.

Иконка: `webui\icon.ico` (вариант H, все размеры до 256 px).
