# UI Kit — Telegram Web A style

Веб-интерфейс `telegram_chats_bot` оформлен в стиле **Telegram Web A / telegram-tt**
(<https://github.com/Ajaxy/telegram-tt>). Вся тема оформления вынесена в
`telegram-theme.css`, который подключается в `index.html` **после** `style.css`.

- Разметка и id/классы, на которые опирается `app.js`, не менялись (кроме переноса
  двух кнопок в шапку сайдбара — id `btnFindUser`, `btnSettings` сохранены).
- `style.css` отвечает за структуру/поведение, `telegram-theme.css` — за визуал
  (цвета, типографика, радиусы, тени, анимации). При конфликте побеждает тема,
  потому что грузится позже и использует те же/более точные селекторы.

## 2. Типографика

- Шрифт: `system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial`.
- База: `14.5px / 1.35`; текст сообщения `15px / 1.35`; имя чата `15px/600`;
  время и метаданные `12px`; заголовки модалок `17px/600`.
- Вторичный текст `12.5–13px`, hints `12px`. Заголовки в Markdown: 18/16.5/15.5/15.

## 3. Компоненты

**Сайдбар** — плоская колонка 420px: шапка «Чаты» + статус соединения, две круглые
иконки действий (`user-plus`, `gear`), поиск-пилюля 40px, список чатов на всю высоту.
Нижнего блока с крупными строками нет. Активный чат залит `--chat-active` с белым
текстом, бейдж непрочитанных — белый на активном.

**Шапка чата** — 56px, аватар 42px, имя 15.5/600, подпись `@username`/статус 13px,
кнопка настроек на мобильных.

**Лента** — «обои»: цвет `--bg` + едва заметный SVG-узор (`--chat-pattern`, 180×180,
opacity ~0.045–0.05) и мягкие радиальные градиенты. Разделитель дат — пилюля
`--day-bg/--day-text` с blur.

**Пузыри** — `12px`, группировка `g-first/g-last` (рендерит `app.js`): у последнего
сообщения группы нижний угол `6px` и хвостик-маска (`::after`, `currentColor`,
9×18, выступ 1px, 1px захода под пузырь, чтобы не было шва). Входящие — слева,
исходящие — справа; метаданные 12px, время `tabular-nums`, галочки, «изм.».
Медиа-пузыри ограничены 340px (`:has(.photo-media/.video-media/.video-note)`),
фото ≤320×280, видео ≤320.

**Медиа и файлы** — фото скругляются 9px, кликабельны (lightbox). Карточка файла:
круглая иконка 40px, имя/размер, **заметная круглая кнопка скачивания**
(акцентный фон, тень, hover). Аудио: синий play 40px, волна из 26 полос (активные —
акцентом, в исходящих — белым/зелёным), длительность, кнопка скачивания.
Расшифровка: блок с левой акцентной линией и тонированным фоном.

**Композер** — плавающая пилюля на прозрачном фоне: панель форматирования над полем
(чипы 26px), textarea 15px, attach 38px, круглая кнопка отправки 44px
(`--accent-solid`, disabled — `--panel-3`). Вложения — чипы над пилюлей.

**Настройки** — модалка 860px, радиус 16px: шапка 17px + подпись, левый таб-бар
(208px, фон `--settings-side`, активный таб — тонированный акцент), правые панели.
Строки-переключатели — не карточки, а строки с разделителями; свитч 40×24.
Поля/селекты 40px на `--input-bg`; превью тем — мини-скриншоты с реальной палитрой.
Кнопки — пилюли: primary `--accent-solid`, ghost с рамкой, danger — тонированный.

**Прочее** — тосты 12px-радиус с цветной левой полосой; lightbox с blur и акцентной
кнопкой скачивания; dropzone с пунктирной акцентной рамкой; пустые состояния с
круглым логотипом.

## 4. Адаптив

- `>1400px` — сайдбар 420px.
- `≤1400 / ≤1180` — 380 / 340px.
- `≤900px` — сайдбар уезжает в overlay (360px), появляются burger и мобильная
  шестерёнка, таб-бар настроек становится горизонтальным со скроллом.
- `≤600px` — пузыри 88%, меньше отступы, медиа 300×260.
- `≤430px` — превью тем в одну колонку, подписи табов остаются видимыми.
- `prefers-reduced-motion` отключает анимации.

## 5. Отличия от telegram-tt (наша специфика)

- Нет «островного» макета (скруглённые колонки с отступами) и папок/историй/стикеров —
  плоский сайдбар и одна колонка чата, как в Telegram Web A.
- Тёмная палитра — классическая night (`#0e1621/#17212b/#2b5278`), а не современная
  `#212121/#766AC8` из telegram-tt.
- Наш функционал: расшифровка речи (модели, прогресс, статусы), управление
  пользователями, лимиты Bot API, кнопки скачивания медиа/файлов/аудио, Markdown.
- Иконки — собственный SVG-спрайт, без иконочного шрифта telegram-tt.
- Активный чат в светлой теме — синий `#3390ec` (как в Telegram), в тёмной — `#2b5278`.
